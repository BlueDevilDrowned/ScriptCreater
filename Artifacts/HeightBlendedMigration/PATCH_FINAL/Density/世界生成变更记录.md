# 世界生成变更记录

从 2026-10-19 开始记录。后续修改按日期追加，保留目的、原因、公式、验证结果和未完成项。历史讨论不等于已实现；实现状态以代码和验证记录为准。

## 2026-10-19：XZ 地形参数控制垂直密度曲线

### 目的与原因

让同一 `(x,z)` 下不同高度共享大陆性、侵蚀度、山脊度及样条参数。此前这些参数直接采样三维噪声，沿 Y 会改变，相当于一根柱子在不同高度切换地形环境。

此前 `Jaggedness` 直接作为正向密度相加，不是源码中“山脊噪声的强度”；公开的 `Depth` 也错误地指向独立噪声，没有返回实际参与地形计算的深度。

### 修改内容

- 新增独立类 `ProjectedXZFunction`，把采样坐标的 Y 固定为 0。保留三维 Value Noise，实现简单的二维切片；这不是二维缓存，也不是原版 shiftedNoise2d 的精确复刻。
- 新增 `ProjectXZ`、`Noise2D`、`HalfNegative`、`QuarterNegative`、`NoiseGradientDensity` 工厂方法。
- Continents、Erosion、Ridges 改成二维输入；嵌套样条计算出的 Offset、Factor、Jaggedness 随之只依赖 XZ。
- Temperature、Vegetation 也改为二维基础气候场；尚未接入原版群系选择器、温度高度修正或材质规则。
- Jaggedness 改为乘以二维 JaggedNoise 的 HalfNegative 结果，再放到 Factor 乘法内部。
- 按源码顺序先乘 Factor，再 QuarterNegative，最后乘 4。
- `WorldFields.Depth` 返回实际的 `YGradient + Offset`。
- 保留当前三维基础噪声与上下边界滑动。

### 当前公式和原理

```text
C = Continents(x,z), E = Erosion(x,z), R = Ridges(x,z)
O = OffsetSpline(C,E)
F = FactorSpline(E)
J = JaggednessSpline(R)

V(y) = lerp(0.75, -0.75, clamp(y / 160, 0, 1))
Depth = V(y) + O
JaggedTerm = J * HalfNegative(JaggedNoise(x,z))
T = F * (Depth + JaggedTerm)
Terrain = 4 * QuarterNegative(T)
RawDensity = Terrain + 0.35 * Base3DNoise(x,y,z)
FinalDensity = VerticalSlide(RawDensity)

HalfNegative(v)    = v >= 0 ? v : v * 0.5
QuarterNegative(v) = v >= 0 ? v : v * 0.25
```

O 改变竖直曲线的位置；F 改变密度随高度下降的速度，以及基础 3D 噪声的相对影响。忽略噪声时，正的 F 不改变零点，因此不能简单解释成“F 越小地形越平”。J 控制有正有负的山脊扰动幅度，不再一律增加密度。

在 0～160 内，`dV/dy = -1.5/160`。固定 XZ 时，O、F、J 都不变；忽略基础 3D 噪声与边界滑动，T 的斜率就是 `-1.5*F/160`。QuarterNegative 再让负值部分的斜率缩小四倍。Y 方向变化有明确的数学来源。

### 源码依据和当前差异

Minecraft Java 1.20.1：`NoiseRouterData.registerTerrainNoises`、`noiseGradientDensity`、`DensityFunctions.Mapped`。

纠正此前讲解：源码 JaggedNoise 的 Y 倍率为 0，也是二维变化；二维性来自噪声采样设置，而不是 cache2d 自动把任意三维噪声变成二维。

本次移植组合结构，保留学习版尺度：原版垂直梯度为 `(-64,320,1.5,-1.5)`，项目仍为 `(0,160,0.75,-0.75)`。坐标单位是体素采样坐标；0.5 的显示尺寸不改变此范围。预览高度 128 只截取世界的一段，顶部不必为空，调整采样起点会移动这个窗口。

仍未复刻原版样条控制点、Offset 的 -0.50375 校准、shiftedNoise2d、BlendedNoise、洞穴与群系选择。上下滑动仍是已有学习版参数，不能据此声称完整复刻原版世界生成或消除所有悬浮块。

## 2026-10-19：统一世界高度与分形混合基础噪声

- 新增独立 `WorldGenerationSettings`，世界范围为 `[MinY, MaxYExclusive)`，默认 `[0,160)`，单位是体素坐标。Inspector 可编辑；预览窗口仍独立，越界时报错，密度函数自身仍可在任意 Y 采样。
- 垂直梯度端点单独配置，不随预览窗口移动。上下滑动使用统一世界边界，默认厚度 24；拒绝倒置范围、重叠滑动、非有限参数等。
- 新增独立 `OctaveNoiseFunction`、`BlendedNoiseFunction`；分形采用频率翻倍、振幅减半、除以权重总和的 ValueNoise。每层独立稳定种子，支持不同 XZ/Y 频率。
- A/B/选择场各 4 层。A/B 默认 XZ=0.02、Y=0.01；选择场 XZ=0.008、Y=0.004。最高层频率限制为每体素 0.5，避免配置明显超出体素采样能力。
- `t=clamp((selector+1)/2,0,1)`，`Base3D=Strength*lerp(A,B,t)`；默认 Strength=0.35。替换原单层基础噪声，不改变二维环境场与算子顺序。
- 这是学习版结构，不复刻原版 ImprovedNoise、16/16/8 octave、smear、随机序列和数值尺度。分形与混合同时使用。
- 验证记录位于 `Artifacts/HeightBlendedMigration/VERIFICATION.txt`，包含原状态、修改、回滚及独立检查。Unity 场景视觉结果尚未检查。
